## 2. THE DESIGN DIRECTION

Create a sophisticated, editorial-style personal portfolio with the visual quality of a carefully art-directed personal brand website.

The result should feel contemporary, confident, intelligent, approachable, and memorable.

Avoid:
- Generic student portfolio templates.
- Overused gradient backgrounds and excessive glassmorphism.
- Unnecessary glowing effects.
- Excessive rounded cards.
- Random floating shapes and decorative elements without purpose.
- Walls of text.
- Emoji used as interface icons.
- Fake statistics, invented testimonials, fabricated awards, or imaginary work experience.
- Animations that make the website feel slow or distracting.

### Visual identity

Build a distinctive design system using:

- Deep forest green or near-black as a strong anchor color.
- Warm ivory or off-white for readable editorial surfaces.
- Restrained lime or fresh botanical green as an accent.
- A refined typography pairing: a contemporary sans-serif for interface text and a distinctive editorial serif for selected headlines.
- Generous whitespace, strong grid alignment, beautiful spacing, clean borders, and excellent contrast.
- Large expressive typography and carefully controlled image crops.
- Consistent spacing, typography scales, button styles, and section transitions.

The visual identity should subtly connect agriculture, forestry, sustainability, environmental stewardship, and modern ambition without looking like a farm brochure.

Make deliberate design decisions. The final website should look polished at first glance and remain visually interesting as the visitor scrolls.
